# 실행·검색·선택 이벤트 공유

[Java 처리 결과](https://devdooly.github.io/devdooly-platform-lab/#lab)의 **이벤트 상세 → 실행·검색 조건 공유**에서 현재 실행 ID, 검색어, 처리 상태, 사유 원문, 센서 정확 조건, 선택한 이벤트 순서를 링크에 담습니다. 복사 버튼과 직접 선택할 수 있는 URL 입력을 제공합니다.

## 링크를 열고 적용하기

링크를 열면 요청한 실행과 조건을 별도 카드에 표시합니다. 기존 첫 화면의 일반 조회는 유지하지만 공유 대상 실행의 추가 조회와 조건 적용은 **공유한 실행·조건 조회**를 눌러야 시작합니다. 실시간 API 연결 상태에서만 적용할 수 있으며 게시 관측·고정 샘플에서는 기존 ‘실시간 조회’로 연결을 복구하도록 안내합니다.

최근 목록 밖의 ID도 기존 공개 상세 GET으로 직접 읽습니다. 요청 ID와 응답 ID가 일치하고 형식 검증을 통과한 경우에만 상세 결과와 검색·선택을 함께 적용합니다. 조회 실패 시 이전 실행·필터·선택을 유지하고 실패를 표시합니다. 다른 실행이나 fallback의 같은 순서 이벤트를 대신 선택하지 않습니다.

선택은 eventId나 배열 위치가 아닌 응답의 sequence를 사용합니다. 지정한 순서가 없으면 미선택으로 남기고, 해당 이벤트가 검색·상태·사유 조건에서 제외되면 조건을 넓히지 않고 그 이유를 표시합니다. 화면을 다시 조작하면 이전 적용 완료 문구를 현재 조건의 성공처럼 남기지 않습니다.

## URL 형식과 해석 범위

같은 사이트의 고정 루트 경로와 `#lab`을 사용합니다. `labRun`, `labStatus`, `labQuery`는 각각 하나가 필요하고 `labReason`, `labSensor`, `labEvent`는 선택 항목입니다. 사유 부재는 전체 사유, 빈 사유 값은 빈 문자열 조건입니다. 센서 부재는 전체 센서, `labSensor=`는 빈 문자열 센서와 정확히 일치하는 조건입니다. 센서 조건이 없는 기존 URL은 형식을 유지하며 이를 적용하면 기존 정확 센서 조건도 해제합니다. 원문 공백·대소문자·기호는 인코딩해 보존합니다. 센서 문자열이 URL 변환으로 달라질 경우 링크를 만들지 않습니다. 상태는 기존 다섯 값, ID는 기존 실행 ID 형식, 이벤트 순서는 0 이상 안전한 정수의 정규 표기만 받습니다.

이 기능의 중복 키·알 수 없는 lab 접두어 키·불완전한 조건은 적용하지 않습니다. 근거 검색 등 다른 기능의 매개변수는 읽지 않아 공존할 수 있으며 생성하는 링크에는 실행 탐색 조건만 담습니다. URL에서 API 주소나 임의 목적지를 받아들이지 않습니다.

공유한 것은 다시 찾을 조건입니다. 응답 원문·원 관측 시각·당시 코드 버전을 고정하는 링크가 아니며, 재조회 시의 출처와 상세 observedAt을 따로 표시합니다. 그 시점에 표시된 행과 조건·출처·원 시각을 보관하려면 [CSV·JSON 저장](event-export.md)을 사용합니다. 조회 실패나 없는 이벤트를 새 결과로 대체하지 않습니다.

## 검증과 유지 범위

로컬 웹 333개·생략 0, Astro 69파일의 진단 0과 4페이지 빌드를 통과했습니다. 원문 roundtrip, null·빈 사유, 잘못된 키·ID·정수, 없는 이벤트·필터 제외와 실제 적용 함수의 성공·실패 보존·실시간 연결 경계·연속 호출·늦은 응답 폐기를 검사했습니다. 독립 모델 검토는 61개 사례·81회 호출을 사용했으며 UI 검토에서 발견한 새로고침 후 사라진 선택 번호의 공유 경로도 수정했습니다.

실제 로컬 브라우저에서는 링크 복사 후 붙여넣기, 재열기 전 미적용, Enter 적용, 1,000건 중 sequence 996의 원문 조건과 한 행 복원, 404 때 이전 실행·조건·선택 보존, 없는 순서·필터 제외·중복 URL 키의 미적용을 확인했습니다. 모바일 375px의 가로 넘침 0, 글자 17px와 51px 이상 조작부를 확인했습니다. 병합 main의 CI·Pages와 실제 공개 브라우저 결과는 PR에 따로 기록하며 로컬 확인으로 대신하지 않습니다. 서버 실행 생성이나 Kafka·S3 작업을 추가하지 않습니다.

Pages 토큰 교체·별도 K3s/Jenkins 기동 복원·자원 예산 정책·PR102는 보류합니다. 운영 image/source pin·기존 서비스·자료·자동 이미지 제안 PR·3개 PAUSED는 유지합니다.
