# 같은 이름의 실행 결과 구분

2026-10-21 UTC의 공개 화면에서 실행 결과 선택 항목10개가 모두 같은 이름·seed로 표시됐습니다. 저장된 실행 ID는 달랐지만 화면에는 보이지 않아 새 worker 검증과 이전 입력1,000건의 결과를 구분하기 어려웠습니다.

선택 항목 앞에 실행 ID와 입력 건수를 표시하고 기존 이름·seed도 유지합니다. 선택한 실행의 전체 ID는 결과 설명 아래에 표시하며 `aria-describedby`로 선택 입력과 연결합니다. 소개의 고정 ‘12개’를 제거해 실제 건수가 다른 실행에도 맞게 했습니다.

선택값·키·이벤트 처리·API 요청·데이터·CSS는 그대로입니다. 이번 변경은 표시를 개선하며 새로운 작업을 실행하거나 저장 자료를 수정하지 않습니다.

## 로컬 확인

- 웹207개 통과·생략0, Astro 타입47파일의 오류·경고·힌트0, 프로젝트 경로의 정적2페이지 빌드를 확인했습니다.
- 기본 데스크톱과390px 모바일에서 실행 ID와 입력 건수, 선택한 전체 ID 및 설명 연결을 확인했습니다. 문서 폭은 각각1265/375px로 client 폭과 같았고, 모바일 선택 입력은303px로 화면 안에 표시됐습니다.
- 로컬은 기존 게시 관측으로 fallback하는 읽기 화면입니다. 여기의 화면 검증을 미니 PC의 실제 여러 실행 선택·새 작업 처리·외부 API 성공으로 바꾸어 기록하지 않습니다. 공개 API의 별도 [GET6 관측](../public-get/README.md)과 [새 worker 처리 실측](../current-worker-fixture/README.md)은 각각의 범위를 따릅니다.
