# 실행 결과 탭의 키보드 이동

2026-10-21 KST, 브라우저에서 기존 공개 화면과 수정한 로컬 화면을 대조했습니다.

## 문제와 수정

기존 화면에서 `시계열 결과`의 왼쪽 방향키와 `이벤트 상세`의 오른쪽 방향키는 선택을 바꾸지 않았습니다. 두 탭의 키 처리를 하나로 모아 양 끝에서도 순환하도록 수정했습니다. Home은 첫 탭, End는 마지막 탭으로 이동합니다.

선택한 탭에만 `tabIndex=0`을 유지하고, 초점·`aria-selected`·표시하는 패널을 함께 바꿉니다. Ctrl·Alt·Meta 조합과 다른 키의 기본 동작은 가로채지 않습니다. 조회 데이터와 API 계약은 그대로입니다.

## 실제 확인한 범위

- 양쪽 탭 각각에서 Left·Right·Home·End, 총 8가지의 선택·초점·숨김 패널 일치.
- 이벤트 탭의 Tab으로 처리 상태 선택에 진입하고 Shift+Tab으로 선택한 탭에 복귀.
- Ctrl+Left 뒤 선택 보존, 클릭과 기존 선택 기능 유지.
- 1280px·390px에서 선택 초점 표시와 페이지 가로 넘침 부재. 모바일 최종 확인은 실제 viewport 390·문서 폭375로 대조했습니다.
- 기존 웹 검사207개 통과·skip0, Astro46파일 오류0·경고0, 프로젝트 경로 빌드 통과.

207개는 기존 데이터·관측 계약 검사이며 탭의 브라우저 동작 8가지와 구분합니다. 별도 서버 배포·실행기 장애 시험을 수행한 결과는 아닙니다.
