# Astro React Lab UI 구현 시작점

1단계에서 합성 데이터의 결과와 처리 흐름을 보여줄 화면을 구현할 위치입니다. 현재 Node 프로젝트나 화면 코드는 없습니다.

Astro 정적 페이지와 필요한 React 컴포넌트로 시작합니다. Node·패키지 매니저·Astro 버전과 lockfile을 정하고, 같은 Lab 호스트의 `/api`로 조회합니다. 공개할 상태·건수·관측 시각을 명시하고 계획 중인 기능은 구현 상태와 구분합니다.

이 Lab UI는 미니 PC에서 서비스할 실행 화면입니다. 소개와 경력을 제공하는 GitHub Pages 포트폴리오는 1단계에서 주소와 저장소를 확인한 뒤 별도로 구성합니다.
