# Spring Boot API 구현 시작점

1단계에서 합성 데이터 작업과 결과 조회를 구현할 위치입니다. 현재 애플리케이션과 빌드 설정은 없습니다.

먼저 Java·Spring Boot·빌드 도구 버전을 선택하고 wrapper를 추가합니다. MariaDB의 샘플 schema, 데이터 seed와 기대 결과를 정의한 뒤 작업 결과 목록과 단건 조회부터 구현합니다. API 경로 제안은 [전체 계획](../../docs/PROJECT_PLAN.md)의 9절을 따릅니다.

Kafka와 S3 연동은 4단계에서 추가합니다. 첫 단계에 관리 API나 무제한 공개 실행을 포함하지 않습니다.
