# 공개 예제의 측정

5단계에서 LLM을 활용한 코드 개선 사례와 재현 가능한 성능 비교를 추가합니다. 현재 benchmark 코드나 측정 수치는 없습니다.

개인이 만든 연산·시간 처리 예제에서 개선 전후 정확성을 먼저 확인합니다. 입력 크기와 seed, 하드웨어·JVM·라이브러리·commit, warm-up과 반복 횟수를 기록하고 원본을 보존합니다. 입력 크기별 비교와 시간복잡도 분석의 근거를 함께 설명합니다.

AI가 제안한 내용, 채택·수정·기각한 이유와 사람의 검증을 구분합니다. 개인 예제의 결과를 실무 알고리즘이나 실제 회사 성과로 표현하지 않습니다.
