# 합성 데이터와 검증 시나리오

1단계에서 첫 API 계약을 정할 때 작은 seed 데이터와 독립적인 기대 결과를 추가합니다. 현재 테스트 코드와 fixture는 없습니다.

정상·빈 입력·중복 키·잘못된 시간·시간 역순·실패 후 재처리를 우선 정의합니다. Kafka 도입 이후에는 consumer 중단·재시작과 중복 이벤트의 최종 결과를 확장합니다.

입력 데이터는 개인이 만든 합성 데이터만 사용합니다. 정답을 구현 코드의 결과에서 그대로 가져오는 테스트는 피하고, 각 시나리오의 기대 건수와 상태를 먼저 설명합니다. 시나리오 검증은 관련 앱의 실제 테스트 도구와 연결하고 결과는 [검증 기록](../../docs/evidence/README.md)에 남깁니다.
